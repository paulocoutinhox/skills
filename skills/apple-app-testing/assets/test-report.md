## Reproducible findings

For each defect, record:

1. Concrete title, user impact/severity and separate priority.
2. Exact build/destination, account role, current window/scene and initial state.
3. Minimal ordered reproduction with the real input method.
4. Agreed expected behavior and observed UI/durable effect.
5. First occurrence, frequency and all subsequent attempt outcomes.
6. Sanitized screenshots/video, relevant logs, result bundle and matching symbols if needed.
7. Demonstrated cause when known, affected consumers and requested fix verification.
