## Reproducible findings

For each defect, record:

1. A specific title, user impact/severity and a separate priority.
2. Exact build/destination, account role, current window/scene and starting state.
3. The shortest ordered steps to reproduce it with the real input method.
4. The agreed expected behavior and the UI/saved effect you saw.
5. First time it happened, how often, and the outcome of every later attempt.
6. Cleaned screenshots/video, relevant logs, result bundle and matching symbols if needed.
7. The proven cause when known, what else uses the affected code and the requested fix check.
