# Publication intake and outputs

## Brief fields

| Group | Collect or decide |
| --- | --- |
| Editorial | Title, subtitle, author and contributors, language, audience, purpose, manuscript status, edition, publication year, publisher imprint if any. |
| Rights | Who owns the manuscript, permissions for quotations and reference images, illustration rights. Platform declarations, such as an AI-content question in a distributor's form, are answered in that form and never printed in the book. |
| Format | Book or workbook, print/digital/both, reading direction, trim dimensions, page orientation, expected length. |
| Style | ABNT-based editorial default, strict academic format, or another named style and edition. Institutional overrides if applicable. |
| Typography | Arial 12 default, body text justified to both margins, hyphenation language, approved font files and licensing, heading hierarchy, quote/note/caption sizes, cover display typography. |
| Structure | Half-title, title page, internal cover sides, copyright, dedication, epigraph, acknowledgments, preface or introduction, contents, list of figures, list of tables, abbreviations, body, conclusion, references, glossary, appendices, index, author biography. Collect the author's own wording for the dedication, acknowledgments and biography. |
| Images | Locations, narrative purpose, generation brief, figure titles above images, credit/source below, alternative text, list of figures. The generation brief stays in production records. Captions, credits and alternative text describe the image, not how it was made. |
| References | Author-date or numeric citation system, footnote purposes, source inventory, exact quotations and locators. |
| Pagination | Lower center, lower right/outer, upper right/outer, first counted page, first displayed number, blank-page policy. |
| Manufacturing | Printer template, cover stock and weight, cover ink, lamination, interior stock and weight, interior ink, binding, flaps, bleed, color profile, marks policy. |
| ISBN | Existing ISBN-13, format/edition it identifies, whether barcode supplied by production service, price supplement if explicitly required. |

Make clear that “index” may mean a table of contents or a subject index. A subject index needs chosen terms and page references. Offer both when useful instead of quietly using one in place of the other.

## Binding choices

Offer the requested options with what each one needs in production: square-spine perfect binding, sewn binding, hardcover, hardcover with a concealed spiral, exposed spiral or wire binding, saddle stitch, and another printer-supported finish. Do not suggest that every printer supports every combination. Hardcover requires boards, joints, turn-ins, and possibly a separate jacket. Spiral needs a punch-safe area and usually has no printable conventional spine. Saddle stitch needs the printer's signature and creep rules, often a page count divisible by four.

## Output matrix

| Mode | Deliverables |
| --- | --- |
| Digital PDF | Reader PDF with working contents and cross-references, selectable text, fitting metadata and accessibility, no crop marks, PNG cover masters. Include the cover in the reader PDF only if chosen. |
| Print | Interior PDF as single pages, production cover PDF as a flat spread, front/back/full-wrap PNG artwork or previews, editable sources, production manifest. |
| Both | Separate print and reader PDFs plus shared editable sources and all requested cover masters. |
| Reflowable ebook, if requested | EPUB with navigation and semantic structure, validated separately, plus a compatible storefront cover export. A PDF alone is not a reflowable ebook. |

Suggested filenames are `interior-print.pdf`, `book-digital.pdf`, `cover-front.png`, `cover-back.png`, `cover-wrap.png`, `cover-print.pdf`, and `production-manifest.json`. Do not export a useless back–spine–front print wrap for a digital-only publication unless requested. Keep a front-cover PNG master even when a storefront needs a JPEG or TIFF derivative.

Do not promise a finished manuscript from an outline without really writing and reviewing it. For long books, keep chapter sources, a source inventory, a style sheet, and a build command so the work can be rebuilt the same way.
