# Images and cover design

## Art direction

Base the cover on the book's genre, promise, audience, tone, and title hierarchy. Choose readable, licensed display type. Arial 12 for body text does not decide the cover type. Keep the title, subtitle, author, series information, and spine readable at their real physical and thumbnail sizes.

Use a planned palette and a clear focal point. Keep the front and back layout unified across the spine, without placing key faces or lettering on folds. Put the back-cover copy, author biography, optional publisher mark, and a reserved barcode patch into separate safe areas. Match exact author and title metadata across every output.

## Image-model workflow

Create an image list with purpose, placement, aspect ratio, generation prompt, target physical size, resolution, caption, credit, and alternative text. The prompt is a production record kept outside the book. The caption, credit and alternative text describe what the image shows and credit it as the brief specifies, for example "Source: prepared by the author (2026)". They never mention a model, a prompt or generation. Generate original illustrative artwork using the available image model. If none is available, report that need and ask for a supported way to generate images, instead of claiming images were generated.

Use the same visual direction across a series. Ask for reference images when a person's likeness or an exact object matters. Check faces, hands, perspective, object proportions, repeated motifs, unwanted text, and artifacts. Regenerate or edit flaws. Do not stretch or squeeze an image. Crop on purpose or scale it to fit without changing its proportions. Do not claim that setting DPI metadata adds missing pixel detail.

Set body text, precise labels, formulas, charts, and barcodes with layout tools that give the same result every time. A generated image can supply the cover artwork while editable type supplies reliable spelling and spacing. A chart of real measurements must come from checked data, not an invented model illustration.

## Resolution and placement

For print, calculate effective resolution as source pixels divided by placed inches. Target at least 300 ppi for continuous-tone artwork in the supported production profile. Line art may need higher resolution or vector output. Generate a large PNG master, keep it, and export color-managed print copies and RGB digital copies separately. PNG uses RGB or grayscale and is not a CMYK press container.

Keep captions attached to their figures. Do not allow a page break inside an ordinary image and caption block. Move the block or redesign a large figure instead of clipping it. Multi-page diagrams need planned panels with labels that show they continue. Large tables need readable repeated headers, not conversion to an image or tiny scaling. Review the crop-safe, fold-safe, and binding-safe regions one at a time.
