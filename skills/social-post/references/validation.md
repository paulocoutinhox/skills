# Editorial validation without automation

This skill is descriptive. It does not bundle or create counting scripts, parsers or publishing automation.

Validate the actual final payload, including spaces, line breaks, hashtags, mentions, disclosures and links. Use the native publishing interface's counter and preview when available. Distinguish code points, UTF-8 bytes, UTF-16 units and X weighted text. A raw string length is not exact evidence for every surface.

For YouTube tags, separating commas and the platform's quote accounting for tags containing spaces consume budget. Tags and visible hashtags are different fields. For X, recognized URLs and supported emoji sequences use platform-specific weighting. Do not estimate an exact accepted count from visible character length.

If native validation is unavailable, state the field's researched ceiling and unit, explain what was checked editorially, and mark platform acceptance unverified. Do not introduce an implementation just to simulate certainty. Recheck the final pasted text after changes.

Record field, surface, limit/unit and actual validation status in the delivery. Verify links, spelling, factual claims, accessibility and disclosures independently of character count. Neither a valid length nor a successful preview proves that the message is accurate or persuasive.
