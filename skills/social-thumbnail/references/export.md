# Descriptive export procedure

Use the available image editor/export interface. This skill does not bundle or create conversion scripts.

Preserve the original high-resolution PNG and editable typography/layout. Select the actual required canvas, file format, byte ceiling, crop/fit and encoder quality. Do not stretch proportions, overwrite the source or silently change settings after a failed export.

A proportional crop removes image area. A contain operation preserves the entire source and adds a deliberate background. Choose the treatment that keeps the content promise and all essential text/subjects. Review every platform crop separately.

Apply orientation and convert known color profiles appropriately to typical sRGB delivery. JPEG requires deliberate alpha flattening. An untagged image has an uncertain source color interpretation, so inspect its actual workflow rather than claiming automatic color correctness.

Reopen the exported file. Check dimensions, actual format, bytes, orientation, crop, glyphs and small-scale readability. A quality setting of 99 is not a guarantee of file size or perceptual identity. If the chosen target fails, explain the concrete tradeoff and use an authorized adjustment.

Report the actual master/derivative dimensions, format, quality setting where available, bytes and inspection results. Do not claim that unavailable file properties or platform acceptance were checked.
