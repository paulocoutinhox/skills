# Logo assets

`logo-master.png` is the original transparent raster master generated with the built-in image tool.
`logo.svg` and `logo-dark.svg` are editable geometric interpretations of its modular-P concept. They contain flat paths
and a live-text wordmark using an available sans-serif stack. It does not embed the PNG or claim
outlined conversion of the generated lettering. The README selects the appropriate vector palette
with a picture source rather than assuming the embedding surface has the system's background color.

Both vectors use teal `#22C7B5` for the wordmark and secondary module. The light-background vector
uses indigo `#4f46e5` for the main module, and the dark-theme vector uses lighter indigo `#818cf8`.
Inspect the palettes on both white and dark backgrounds because image previews can display a
different background from the selected theme. Keep the geometry, wordmark spacing and transparent
canvas consistent between variants.

Generation brief: a professional horizontal Paulo Skills identity, simple interlocking modular P,
deep indigo and dark ink, readable sans-serif lettering, transparent background, clear space, and
no book, sparkle, gradient, shadow, mockup, or tagline. The original PNG remains for inspection.

## Generation prompt

```text
Create a completely new professional brand logo for the open-source project named exactly 'Paulo Skills'. A premium, clean, modern identity for researched modular engineering knowledge. Horizontal lockup on transparent background, a distinctive simple flat geometric symbol at left and a precisely legible dark-ink wordmark 'Paulo Skills' at right. Symbol concept: two or three interlocking rounded geometric modules suggesting a letter P and organized capabilities. Very few shapes, strong negative space, harmonious spacing, consistent optical weight. Restrained deep indigo accent and near-black ink. Flat solid fills with crisp edges, easy to trace into genuine vector paths and recognizable at favicon scale. Wordmark is refined contemporary sans serif, excellent kerning. Generous transparent clear space around the complete lockup. Deliver one final logo, not a contact sheet, mockup, presentation board, or photograph. No book, sparkle, star, gradient, 3D, shadow, colored background card, tagline, code brackets, tiny details, or distortion. Large high-quality PNG master.
```

The built-in image tool produced the PNG. The SVGs are editable project-native interpretations,
not the tool's claimed native vector output. Their palettes are selected through the README picture.
